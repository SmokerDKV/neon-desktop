# NEON SHELL · 霓虹赛博桌面外壳

一个运行在 Windows 上的**全屏桌面外壳**：把桌面图标换成可平移缩放的**蜂窝地图**，用一条贴着屏幕边缘的**状态栏**替代任务栏，再配上屏中底部的**拾音条**和一个与 **MineRadio** 实时同步的**简洁播放器**，右下角还有复刻系统托盘的**时钟 / 网络 / 音量 / 电池**。整体暗色霓虹风格（青 / 品红 / 紫），零编译、零 npm 依赖。

![NEON SHELL 界面预览](docs/preview.jpg)

> 左上：蜂窝桌面（真实桌面项目）｜底部：拾音条 + MineRadio 播放器 + 贴边状态栏｜右下角：系统托盘

## 一、快速开始

### 环境要求

| 依赖 | 说明 |
|---|---|
| **Windows 10 / 11** | 外壳依赖 Edge kiosk、WebView2、SMTC、PowerShell，仅支持 Windows |
| **Node.js 18+** | 后端只用到内置模块，零 npm 依赖；`node -v` 能出结果即可 |
| **Microsoft Edge** | 系统自带的即可，外壳用它承载全屏界面 |

> 想做到「双击即用、完全不依赖系统 Node」：下载 Node 的 **win-x64 便携版压缩包**，把里面的 `node.exe` 放进工程 `runtime/` 目录——启动器会**优先**用它，找不到才回退到系统 PATH 里的 `node`。

### 启动

双击工程根目录下的 **`启动 NEON SHELL.vbs`**。

- 没有任何黑窗口，1~2 秒后自动弹出 **Edge 全屏窗口**（kiosk 模式，覆盖任务栏）——这就是外壳界面。
- 建议：右键 `启动 NEON SHELL.vbs` → **发送到** → **桌面快捷方式**，以后从桌面一键启动。
- 如果 Edge 的 kiosk 窗口没有起来，多半是 Edge 不在默认安装路径，见「七、常见问题」。

### 退出

- 点界面**右上角 ⏻**（或按 **Ctrl+Q**）弹出确认框，点「**退出**」即可——外壳、后端自动全部关闭，**Windows 任务栏自动恢复**。
- 兜底：直接 **Alt + F4** 关掉 Edge 窗口，后端会检测到并一起退出。
- 极端情况（后端异常退出但窗口还在）：按 Alt+F4 关窗口后，重新双击 vbs 再正常退出一次，任务栏即可恢复（启动时会先复位再隐藏）。

> 重复双击启动是安全的：外壳自带**单实例守卫**。若已有实例在运行，新启动的这次会先让旧实例干净退出（恢复任务栏、收起隐藏的后台守护进程），再接管并弹出全屏壳——不会出现两个外壳互相打架、也不是「静默退出」。

### 关于任务栏

外壳运行期间 **Windows 任务栏会被隐藏**（这正是"抛弃任务栏"的实现方式），打开的应用会显示在外壳**上方**，应用自己的子窗口（如另存为对话框）也正常。正常退出外壳时任务栏自动恢复。

| 区域 | 作用 |

## 三、操作手册

### 3.1 蜂窝桌面（唯一的桌面形态）

启动时**自动扫描**你的桌面（`%USERPROFILE%\Desktop` + `C:\Users\Public\Desktop`），把所有快捷方式、文件夹、文件铺进蜂窝。

| 操作 | 效果 |
|---|---|
| 在**空白处按住拖动** | 平移整张地图（像看地图一样找软件） |
| **滚轮** | 以鼠标位置为锚点缩放（50%~220%） |
| **双击图标** | 打开该项目 |
| **单击图标** | 仅选中（青色描边），再点空白处取消 |
| **悬停图标** | 点亮它与相邻项目之间的连线 |
| **拖动图标到空格子** | 把项目移过去 |
| **拖动图标到另一个图标上** | 两者**对调位置** |
| **右键图标** | Windows 同款文件菜单：**打开 / 打开方式… / 剪切 / 复制 / 粘贴到桌面 / 重命名 / 删除（进回收站）/ 打开所在位置 / 属性** |
| **右键空白处** | **刷新 / 粘贴 / 新建文件夹 / 新建文本文档 / 新建 Markdown / 新建批处理 / 打开桌面文件夹** |

> 拖动与点击自动区分：手移动超过 6px 判为平移地图，几乎没动判为点击；同一图标 450ms 内点两次才触发打开，避免误开。
> 剪切 / 复制写的是**系统剪贴板**（CF_HDROP + Preferred DropEffect），可以直接去真实的资源管理器里 Ctrl+V；粘贴同样读系统剪贴板，从 Explorer 复制的文件也能粘到桌面。

面板「桌面图标 · 蜂窝地图」里可调：**连线样式**（蜂窝网格 / 相邻连线）、**节点形状**（圆形 / 方形）、**节点大小**、**缩放**、**名称显示**（常显 / 仅悬停）、**重新扫描桌面**、**回到中心 / 重置视图**。

**新增了软件怎么办？** 装完新软件后，点面板里的「**重新扫描桌面**」即可（或重启外壳）。预置的蜂窝会按需**无限向外扩环**，不会挤爆。

> 早先版本还有一个「自由摆放」的方块图标模式，现已移除——桌面图标**只保留蜂窝地图**这一种形态，界面更统一。

### 3.2 状态栏（替代任务栏）

| 操作 | 效果 |
|---|---|
| **滚轮**（在状态栏区域） | 转动选择槽位，被选中的项会滑到正中间 |
| **单击任意图标** | 切换 / 还原该窗口：最小化的窗口还原并置顶，已在前台的则最小化（与原生任务栏一致） |
| **右键图标** | 弹出「切换到该窗口 / 最小化 / 最大化 / 关闭窗口」菜单 |
| 面板「状态栏贴边位置」 | **上 / 下 / 左 / 右** 四边可停靠，弧形会跟着翻转朝向 |
| 面板「状态栏形态」 | **弧形贴边** / **直条贴边**；可调弧线半径 |

状态栏显示的是**当前打开的所有窗口**（由窗口枚举实时获取，和 Windows 任务栏同源），数量随开关窗口动态变化；窗口不足 7 个时两端显示虚线空位，多余时靠滚轮翻动。

### 3.3 右下角系统托盘

复刻 Windows 任务栏右下角托盘区的功能，霓虹玻璃卡片风格：

| 图标 | 操作 | 效果 |
|---|---|---|
| **🌐 网络** | 悬停 | 提示当前连接名 + IP |
| | 单击 | 弹出面板：网络类型（Wi-Fi / 有线 / 未连接）、连接名、IP |
| **🔊 音量** | 悬停 | 提示当前音量 |
| | **滚轮** | 直接 ±5% 调节（生效到系统主音量） |
| | 单击 | 弹出面板：**滑条**拖到哪改到哪、「**静音 / 取消静音**」按钮 |
| **🔋 电池** | — | 图标内填充随电量变化，**充电中变青色**，角标显示百分比；台式机读不到则显示 `--%` |
| **时钟** | — | `时:分` + `年/月/日 周几`，每秒刷新 |

托盘数据（电池 / 网络 / 音量）由窗口守护进程直接读系统接口（Core Audio COM / `GetSystemPowerStatus` / `Get-NetAdapter`），每 5 秒刷新；音量操作是**真实的系统主音量**（和点任务栏小喇叭是同一个）。

### 3.4 拾音条

- **拖动本体**移动位置，**拖右下角手柄**缩放。
- 靠近屏幕边缘或水平/垂直中心时**自动吸附**，并亮出青色参考线（可在面板关闭「边缘吸附」）。
- 面板可调：**宽度 / 高度**、**渐变配色**（顶部 / 中部 / 底部三个取色器）、**透明度**（15%~100%）。
- 点击拾音条下方的 **系统 / 麦克风 / 模拟** 切换信号源：**系统**＝采集电脑正在播放的内部声音，**麦克风**＝采麦克风，**模拟**＝纯动效不采集。
- 「系统」的实现链路：① 优先找声卡的**回环录音设备**（"立体声混音 / Stereo Mix"）；② 没有则走 Chromium 的**屏幕捕获音频轨**（外壳启动时带了 `--auto-select-desktop-capture-source=Entire Screen`，自动选中"整个屏幕"并附带 Windows 系统混音，**不弹窗、不需要手动勾选"共享音频"**）。选择结果会记住，下次启动沿用；你手动选过其它音源后就不会再自动切。
- 若「系统」始终读不到（日志会提示具体原因）：说明当前 Edge / 声卡禁用了回环捕获，可点「麦克风」或先用「模拟」。

### 3.5 MineRadio 播放器

- 显示的是 **MineRadio 正在播放的内容**（歌名 + 来源平台），标签带「· 同步中」呼吸点。
- **⏮ ⏯ ⏭** 是**遥控 MineRadio**（走系统级媒体控制），不是外壳自己在播。
- **双击播放器** → 打开 MineRadio 客户端。
- 一样支持**拖动 / 右下角缩放 / 边缘吸附**，面板里有宽度、高度滑块和重置按钮。

## 四、MineRadio 是怎么同步的

走 **Windows 系统媒体控制（SMTC）**——系统级媒体接口，**不需要修改 MineRadio 一行代码**。只要 MineRadio 在运行（哪怕暂停），外壳就能读到它的歌名、播放状态、进度，并且能把「播放/暂停、上一首、下一首」发回去。

实测确认：MineRadio 的媒体会话标识为 `com.mineradio.desktop`，外壳能正确抓取并控制（Paused → Playing → Paused 往返正常）。

如果播放器一直显示「暂无媒体」：先启动 MineRadio 并播放一次，让它注册到系统媒体会话即可。

### 运行时数据（不在工程内）

生成在 **`%LOCALAPPDATA%\NeonShell\`**：

| 文件 / 目录 | 说明 |
|---|---|
| `icons/` | 提取出来的应用图标 PNG 缓存（按源文件时间戳 + 大小失效重取） |
| `cover.bin` | 媒体封面缓存 |

## 六、技术架构

| 层 | 方案 | 说明 |
|---|---|---|
| 全屏壳 | **Edge Kiosk**（`--kiosk --edge-kiosk-type=fullscreen`） | 复用系统已有的 Edge，覆盖任务栏 |
| 渲染 | **WebView2** | 现代内核，麦克风 / Canvas / 动态壁纸可用 |
| 后端 | **纯 Node**（只用内置模块，零 npm 依赖） | 监听 `127.0.0.1:45730`（占用则自动 +1 顺延） |
| 桌面扫描 / 图标 | **PowerShell + Shell API**（`SHGetFileInfo` / `SHGetImageList` JUMBO） | 提取 256×256 高清图标，含文件夹与 .lnk 关联图标 |
| 媒体同步 | **SMTC**（PowerShell 常驻守护，TCP `127.0.0.1:45739`） | 状态轮询 + 播放控制 |
| 窗口 / 启动 | **PowerShell 常驻守护**（TCP `HTTP+10`） | 枚举窗口、启动应用并置顶、隐藏/恢复任务栏 |
| 文件操作 | **PowerShell 常驻守护（STA）**（TCP `HTTP+11`） | 系统剪贴板读写（CF_HDROP）、回收站删除、重命名、属性对话框、打开方式 |
| 托盘数据 | **Core Audio COM / `GetSystemPowerStatus` / `Get-NetAdapter`**（并入窗口守护进程） | 音量读写（含静音）、电池、网络连接信息 |

> 守护进程端口由 HTTP 端口派生（`HTTP+9` / `HTTP+10` / `HTTP+11`），**不再是固定端口**；启动时还会清理上一次异常退出遗留的僵尸守护进程，避免"端口被占 → 打开应用/状态栏全部失效"。
> 调试可用环境变量 `NEON_BASE_PORT` 把整套端口搬到别的号段，与正在运行的外壳互不干扰。

选择这条路径的原因：本机**没有 Rust / .NET SDK**，编译 Tauri 需要额外装 1GB+ 工具链；而本机**已有 WebView2 运行时 + Edge + SMTC**，所以「不编译任何东西」是最轻的方案——产物就是几个脚本文件，复用系统已有运行时（`runtime/node.exe` 只是兜底，系统有 Node 时也可以直接用系统的）。

## 七、常见问题

**Q：双击 vbs 没反应 / 没弹窗？**
依次检查：① Edge 是否装在 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`（不在的话改一下 `server.js` 里的 `findEdge()` 路径数组）；② 看 `%LOCALAPPDATA%\NeonShell\server.log` 有没有报错；③ 若日志显示 `another NEON SHELL is running - asking it to quit`，说明旧实例正在被优雅接管，多等 1~2 秒即可。

**Q：点了图标 / 状态栏没反应，打不开窗口？**
先确认后端活着：浏览器打开 `http://127.0.0.1:45730/api/ping`，应返回 `{"app":"neon-shell",...}`。再翻 `server.log`：若出现 `win daemon ... Only one usage of each socket address`，说明守护进程端口被占（旧版本遗留问题，现已通过「端口随 HTTP 端口派生 + 启动清僵尸 + 单实例守卫」修掉）。若仍是旧版本，先退出所有外壳再重启一次即可。

**Q：界面一片黑 / 图标没出来？**
桌面扫描通常 2~3 秒（首次含编译），稍等一下。仍不行就看 `server.log` 里的 `desktop scan FAILED` 行，并确认 PowerShell 没有被策略禁用。

**Q：播放器显示「暂无媒体」？**
先启动 MineRadio 并播放一次，让它注册到系统媒体会话。外壳每 0.8 秒轮询一次。

**Q：MineRadio 播放器左侧没有封面？**
MineRadio 目前未向 SMTC 提供缩略图，属于上游限制，界面已有占位处理。

**Q：拾音条不动 / 只有模拟动效？**
- 想要**电脑内部声音**：点拾音条上的「系统」。正常会提示 `拾音条 → 电脑内部声音（系统混音）`。若提示失败，看具体报错文案——多数是 Edge / 声卡禁用了回环捕获。
- 想要**麦克风**：点「麦克风」，权限被拒时也会自动退回模拟。
- 「系统」模式占用的是一次屏幕共享通道，**切换壁纸或重启外壳后如失效再点一次即可**。

**Q：删除的文件去哪了？**
和 Windows 桌面一样进**回收站**，可以还原。

**Q：重命名后蜂窝没刷新？**
会自动刷新（1 秒内）。极慢的情况下点右键菜单「刷新」或面板里的「重新扫描桌面」。

**Q：状态栏 / 拾音条 / 播放器挡住桌面了？**
三者都支持拖动和缩放；拾音条还能调透明度。也可以直接切状态栏的贴边方向，或把拾音条拖到不碍事的位置。

**Q：CPU / 内存数字准吗？**
准。CPU 来自 `os.cpus()` 的两次采样差分，内存来自 `os.totalmem()/freemem()`，每秒刷新，不再是随机数。

## 八、自定义与扩展

- **改视觉**：全部样式在前端 `public/index.html` 的 `<style>` 里，霓虹主色（`--cyan` / 品红 / 紫）集中在开头的 CSS 变量区，改一处全局生效。
- **改行为**：交互逻辑在同文件底部的 `<script>` 里，按模块注释分段（壁纸 / 蜂窝 / 状态栏 / 拾音 / 播放器 / 主循环）。
- **改图标提取分辨率**：`tools/scan-desktop.ps1` 里调整 `SHGetImageList` 的 jumbo 尺寸。
- **改端口**：`server.js` 顶部的 `BASE_PORT`（HTTP，守护进程端口自动跟随为 `+9` / `+10` / `+11`，无需手改；也可用 `NEON_BASE_PORT` 环境变量临时换号段）。
- **不弹全屏壳调试**：设环境变量 `NEON_NO_EDGE=1` 启动，只跑后端，然后用浏览器访问日志里打印的 `http://127.0.0.1:<port>/`。

## 九、已知限制

1. 仅支持 **Windows**（依赖 Edge kiosk、WebView2、SMTC、PowerShell）。
2. MineRadio 暂无封面图（上游未提供 SMTC 缩略图）。
3. 桌面布局（蜂窝里挪过的位置）当前**不持久化**，重启后按默认顺序重新铺排。
4. 全屏壳本质是 Edge 窗口，**Alt+Tab 仍能看到它**，它不是真正的系统级壁纸层。
5. 拾音条「系统」模式走 Chromium 的屏幕音频捕获，Edge 可能会在角落显示一条"正在共享你的屏幕"的小提示，属系统行为。

## 十、卸载

1. 右上下角 ⏻ 退出（或结束 `node.exe`）。
2. 删除工程目录 `neon-shell/`。
3. 如需彻底清理缓存，删除 `%LOCALAPPDATA%\NeonShell\`。

外壳不写注册表、不装服务、不动系统设置，删除目录即完全移除。
